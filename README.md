# AI Prompt Format Guide 🚀

A comprehensive collection of AI prompt templates designed to make your daily work more efficient and productive.

## 📋 What's Included

This repository contains structured prompt templates for common daily tasks:

- **Task-Based Prompts** - For coding tasks and implementations
- **Code Review Prompts** - For giving/receiving code feedback
- **Feature Development Prompts** - For building new features
- **Problem-Solving Prompts** - For debugging and troubleshooting
- **Documentation Prompts** - For writing guides and docs
- **Real-World Examples** - Copy-paste ready examples

## 📖 Template Overview

### 1. Task-Based Template
Use when you have a specific coding/development task:
```
TASK: [One-line description]
CONTEXT: [Background info]
REQUIREMENTS: [What must be done]
DELIVERABLE: [Expected output]
CONSTRAINTS: [Limitations]
```

### 2. Code Review Template
Use when reviewing or getting review on code:
```
CODE REVIEW REQUEST
REPO/FILE: [Location]
CONTEXT: [What code does]
REVIEW FOCUS: [What to check]
QUESTIONS: [Specific concerns]
EXPECTED OUTPUT: [What you want back]
```

### 3. Feature Development Template
Use when building new features:
```
FEATURE REQUEST
FEATURE NAME: [Name]
USER STORY: As a... I want... So that...
REQUIREMENTS: [Functional requirements]
ACCEPTANCE CRITERIA: [How to verify]
TECHNICAL NOTES: [Tech stack]
DELIVERABLE: [What you need]
```

### 4. Problem-Solving Template
Use when stuck on an issue:
```
PROBLEM STATEMENT
ISSUE: [What's wrong]
SYMPTOMS: [What you observe]
EXPECTED BEHAVIOR: [What should happen]
CURRENT BEHAVIOR: [What actually happens]
ENVIRONMENT: [System details]
ATTEMPTS: [What you've tried]
DESIRED SOLUTION: [Type of answer needed]
```

### 5. Documentation Template
Use when writing guides:
```
DOCUMENTATION REQUEST
TOPIC: [What to document]
AUDIENCE: [Who reads it]
SECTIONS NEEDED: [Chapters]
TONE: [Style preference]
INCLUDE: [Special elements]
FORMAT: [File type, length, structure]
```

## 💡 Pro Tips

### Daily Workflow
- **Morning**: Use quick version to plan (5 min)
- **During Day**: Use specific template for each task
- **Evening**: Quick review of what was done

### Best Practices
1. **Be Specific** - More detail = better results
2. **Give Context** - Explain the "why"
3. **List Requirements** - Use checkboxes
4. **Define Success** - What does "done" look like?
5. **Mention Constraints** - Help AI understand limits
6. **Provide Examples** - Show what you want

### Speed Tips
- Save common variations locally
- Build muscle memory through repeated use
- Copy-paste then customize
- Keep context concise but complete

## 🔄 Iteration Tips

1. **First Response Unclear?** Iterate:
   - Point out what wasn't helpful
   - Ask for clarification
   - Refine your next prompt

2. **Results Too Verbose?** Specify:
   - "Keep it concise"
   - "Only include X and Y"
   - "Remove explanations, just code"

3. **Results Too Brief?** Ask for:
   - "Explain your reasoning"
   - "Include examples"
   - "Add more detail on X section"
